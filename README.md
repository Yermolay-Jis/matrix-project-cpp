NumericCore — это кроссплатформенное консольное приложение с текстовым пользовательским интерфейсом (TUI) для создания, редактирования и выполнения математических операций над матрицами и массивами.

Этот проект является моей основной учебной работой для глубокого погружения в современные практики разработки на C++, включая принципы объектно-ориентированного программирования, управление сборкой 
и создание интерактивных пользовательских интерфейсов.

# Ключевые цели и полученные навыки

Главной задачей проекта было не просто реализовать функционал, а освоить ключевые инженерные подходы:

- Объектно-Ориентированное Программирование (ООП): Проектирование системы с использованием классов, инкапсуляции и композиции для создания гибкой и масштабируемой архитектуры.

- Разделение ответственностей: Четкое разделение кода на логические модули: математическое ядро, обработка файлового ввода-вывода и пользовательский интерфейс.

- Современный C++ (11/14/17): Активное использование возможностей современного C++, включая умные указатели, лямбда-функции и контейнеры/алгоритмы из STL.

- Управление проектом и сборка: Освоение системы сборки CMake для создания кроссплатформенной структуры проекта и управления зависимостями.

- Система контроля версий: Ведение всей истории разработки с помощью Git.

- Создание TUI: Интеграция и использование библиотеки FTXUI для построения интерактивного и удобного консольного интерфейса.

# Сборка и запуск

Для сборки проекта вам понадобятся компилятор C++, поддерживающий C++17, Git и CMake.

1. Клонируйте репозиторий

       git clone https://github.com/Yermolay-dev/NumericCore.git

3. Перейдите в директорию проекта

        cd ./NumericCore

4. Создайте директорию для сборки

        mkdir build | cd ./build

5. Сконфигурируйте проект с помощью CMake

        cmake ..

6. Соберите исполняемый файл

        cmake --build .

7. Запустите приложение

        ./NumericCore

# Архитектурные решения
Одной из главных целей проекта является реализация правильной архитектуры.
- Класс ArrayModel / MatrixModel: Вся логика для хранения данных и выполнения операций инкапсулирована в отдельных классах.
- Модуль UI: Вся работа с библиотекой FTXUI вынесена в отдельные классы, которые ничего не знают о математических операциях, например, класс MatrixOperations или ArrayOperations - они лишь получают данные для отображения и передает команды пользователя в ядро приложения.
